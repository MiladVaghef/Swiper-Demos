# Swiper Demos

<img width="1917" height="908" alt="swiper-js-experiment" src="https://github.com/user-attachments/assets/883ddc22-9e1e-41ce-9b51-64e7037c51da" />

A simple experimental project built with HTML, CSS, and JavaScript to learn and explore different slider types and configurations using the Swiper.js library.

Includes demos of: default slider, pagination, dynamic pagination, navigation, progress bar, and fraction counter.

## Used Technologies

- **HTML5**
- **CSS3**
- **JavaScript (ES Modules)**
- **Swiper.js v12**

## How to Use

### Prerequisites

A modern web browser (Chrome, Firefox, Edge, or Safari).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MiladVaghef/Swiper-Demos.git
   ```

2. Navigate into the project directory:

   ```bash
   cd Swiper-Demos
   ```

3. Open `index.html` in your browser — no build tools required.
